📊 Finance Eye 隐私政策

最后更新：2026年6月4日

数据收集

Finance Eye 扩展仅在您主动配置金十数据 API Key 后，通过该 API 获取实时金融行情数据。

我们不收集任何个人身份信息、浏览历史或使用数据。

API 使用

您提供的金十数据 API Key 存储在 Chrome 本地存储中，仅用于调用金十数据行情接口。该 Key 不会传输到我们的服务器（我们没有服务器）。

存储

扩展使用 Chrome Storage API 存储以下数据（仅存储在本地浏览器中）：

  • 您的 API Key 和偏好设置
  • 最近的行情数据缓存
  • 价格预警记录

权限说明

  • storage：保存设置和缓存行情数据
  • alarms：定时刷新行情
  • notifications：价格预警通知
  • host_permissions (api.jinshijijin.com)：调用金十数据行情API

第三方服务

本扩展依赖金十数据（jinshijijin.com）的API服务。请参阅金十数据官方网站了解其隐私政策。
